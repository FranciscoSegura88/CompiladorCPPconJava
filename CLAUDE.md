## Architecture

3-phase C++ compiler pipeline, all analysis runs in a single `p.parse()` call:

```
.cpp file → ScannerLexicoCpp (JFlex) → parser (JCup) → SymbolTable + SemanticError list
```

**Source files:**
- `src/main/jflex/cpp_lexico.flex` — lexer rules; generates `ScannerLexicoCpp.java`
- `src/main/cup/cpp_sintactico.cup` — grammar + semantic actions; generates `parser.java` + `sym.java`
- `src/main/java/com/compilador/semantico/SymbolTable.java` — scope-stack symbol table
- `src/main/java/com/compilador/semantico/SemanticError.java` — semantic error type
- `src/main/java/com/compilador/CompilerError.java` — lexical/syntactic error type
- `src/main/java/com/compilador/Main.java` — entry point, prints symbol table + error report

**Generated (do not edit):** `target/generated-sources/cup/` and `target/generated-sources/jflex/`

## Key design decisions

**Build order is critical:** JCup runs before JFlex in `pom.xml` because `ScannerLexicoCpp` imports `sym.java` (generated by JCup). Swapping plugin order breaks the build.

**Semantic analysis lives in the grammar:** `parser` (JCup class) owns `tablaSimbolos` and `erroresSem`. Semantic checks happen inline in grammar action code within `.cup`, not in a separate pass.

**Scope stack:** `SymbolTable` uses a `Deque<Map<String,Simbolo>>`. Call `enterScope(name)` before a block body, `exitScope()` after. Global scope is always the bottom frame.

**`insertarForzado`:** Use when a type error already occurred but the variable should still be registered — prevents cascading "undeclared variable" errors for the same identifier.

**Internal markers:** Symbols with names starting `__m__` are used as internal scope markers and are hidden from the printed symbol table output.

**Error reporting:** Lexical/syntactic errors accumulate in `scanner.getErrors()`. Semantic errors accumulate in `p.erroresSem`. Both lists are printed together in `Main` after `p.parse()` completes.

**Semantic error types:** `REDECLARACION`, `NO_DECLARADO`, `TIPO_INCOMPATIBLE`, `CONSTANTE_REASIGNADA`, `METODO_DUPLICADO`, `USO_ANTES_DE_DECLARAR`
